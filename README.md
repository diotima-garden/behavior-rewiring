# behavior-rewiring

A base node in the [diotima-garden](https://github.com/diotima-garden) knowledge garden.
`DAFNE.md` is the manifest an agent reads; this file is the human orientation.

## What this is

A short reference library about **one question**: how does something you've understood
turn into something you automatically *do*?

It is deliberately not a textbook. Any model reading it already knows the general
neuroscience. Its job is **curation** — to say which popular advice survived contact with
the literature and which didn't, so that a practice area built on top of it isn't built
on pop psychology. Several widely repeated claims in this space are graded **F** here.

The one sentence that covers almost everything: **this node is for things you do that you
could learn to catch yourself about to do.** If there is no moment you could notice, the
node has nothing to offer.

## The files

| File | What |
|---|---|
| `principles.md` | The stance. What makes a target trainable, what doesn't, and what counts as progress. **Start here.** |
| `sources.md` | Every claim with a grade A–F. An **F** entry ("this is folklore") is worth as much as an **A**. |
| `protocols/` | Two recipes. `single-target-sprint.md` — pick one thing, watch for it for 30 days, write one line a day. `delay-rule.md` — put a forced gap between an impulse and acting on it. |
| `open-questions.md` | What is honestly unknown, and where the seed material was making things up. |

## What it is good for, and what it isn't

| Kind of target | Verdict |
|---|---|
| **Conversational reflexes** — interrupting, over-explaining, matching someone's heat | **Yes.** This is what it is for. The cue is felt coming, so it can be caught. |
| **Long-standing unhealthy reactions** to a recurring situation | **Yes**, same reason. Slower than it sounds — think months, not weeks. |
| **Substance dependence**, nicotine especially | **Not as the main plan.** The body is chemically involved and the pharmacological evidence dominates. Useful as an adjunct, mostly through removing cues. `sources.md` §9. |
| **"Applying" a philosophy or a skill** | **No.** "Be more stoic" names no moment to catch. Cash it out into one situation and one thing you do in it first. |
| **Changing what you feel** at reflex level | **No.** This governs what you do, not the state behind it. That is exposure and extinction territory, a different literature. `open-questions.md` §4. |

Before mounting this node on a target, check whether the target has a treatment
literature of its own. Where one exists, this node is the second thing to read.

## Three things it insists on

1. **Reading about a pattern changes nothing about the pattern.** Progress is counted in
   reps, never in material consumed.
2. **A plan phrased as "when X, I will *not* do Y" backfires** — it strengthens the habit,
   worst on habits that are already strong. Only replacement plans work.
3. **Writing the rep down is an active ingredient**, not bookkeeping, and the effect is
   larger when the record is physical rather than a mental tally.

## For consumers

Mount at `parents/behavior-rewiring/` and read the files in place. The relationship is
semantic reference, not compilation. This node holds **no memory bank and no logs** by
design — practice logs stay in the grove that owns the practice. `DAFNE.md` has the
mechanics, the no-bank rationale, and the contribution rules.
